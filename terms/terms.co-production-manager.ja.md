# OZU Co Production Manager 利用規約

> 本規約は、ベータ版の公開にあたって定めた暫定版です。内容を確認中であり、確定時に改定することがあります。改定する場合は、第18条に従ってお知らせします。

この利用規約（以下「本規約」といいます）は、株式会社OZU（以下「当社」といいます）が提供する「OZU Co Production Manager」（以下「本サービス」といいます）の利用条件を定めるものです。本サービスを利用するすべての方（以下「利用者」といいます）に適用されます。

## 第1条（適用・同意）

1. 本規約は、本サービスの利用に関する当社と利用者との間の一切の関係に適用されます。
2. 利用者は、本サービスのウェブサイト（https://cpm.ozu-inc.com）でのサインアップ時に「サインアップ」を押すことにより、本規約および当社の[個人情報保護方針](https://ozuresearch.github.io/privacy/)に同意したものとみなされます。
3. 本サービスに関して当社が別途定めるガイドライン、ドキュメント（Docs）その他の定め（以下「個別規定」といいます）は、本規約の一部を構成します。本規約と個別規定が矛盾する場合は、個別規定に特段の定めがない限り、本規約が優先します。

## 第2条（定義）

本規約において、次の用語は以下の意味で用います。

1. 「本サービス」：生成 AI 等により作成された画像・動画・テキスト等について、法規・ブランド・生活者・媒体・競合の観点（5C）から出荷前の確認を行い、判定結果、根拠および修正指示を返すサービスであって、API、MCP（Claude Desktop の拡張機能等）、CLI その他当社が提供する一切の手段を含みます。
2. 「アカウント」：本サービスを利用するために、利用者が電話番号により登録したアカウントをいいます。
3. 「API キー」：本サービスの API、MCP および CLI を利用するために当社が発行する認証情報をいいます。
4. 「入力データ」：利用者が本サービスに送信する画像、動画、テキスト、資料その他のデータをいいます。
5. 「出力」：本サービスが返す判定、確信度、根拠、修正指示、レポートその他の結果をいいます。
6. 「ベータ版」：本サービスのうち、正式提供前の試験的な提供をいいます。

## 第3条（利用登録）

1. 本サービスの利用を希望する方は、当社所定の方法により、電話番号による本人確認とアカウント登録を行い、ベータプログラムに申し込むものとします。
2. 当社は、申し込みの内容を確認のうえ、利用を承認するか否かを決定します。当社は、承認しない場合でも、その理由を開示する義務を負いません。
3. 利用者は、登録情報に変更があった場合、速やかに当社所定の方法により変更するものとします。

## 第4条（アカウントおよび API キーの管理）

1. 利用者は、自己の責任においてアカウントおよび API キーを管理し、第三者に利用させ、または貸与・譲渡してはなりません。
2. アカウントまたは API キーを用いて行われた本サービスの利用は、当該利用者による利用とみなします。
3. 利用者は、API キーの漏えいまたは不正利用のおそれがある場合、直ちに当社に連絡するものとします。当社は、当該 API キーを無効化することができます。

## 第5条（ベータ版の提供条件）

1. 当社が承認した利用者は、2027年3月31日まで（以下「無償期間」といいます）、ベータ版を無償で利用できます。ただし、当社は、1か月あたりの利用回数、クレジット等の上限を定めることができます。
2. ベータ版は試験的に提供されるものであり、当社は、事前の予告なく、その内容・機能・仕様を変更し、または提供を中断・終了することがあります。
3. 当社は、無償期間の終了後、本サービスを有償で提供することがあります。その場合、料金その他の条件を事前に通知し、利用者が当該条件に同意したときに限り、有償での利用に移行します。同意がない場合、利用者による本サービスの利用は無償期間の終了をもって終了します。
4. 当社は、ベータ期間中、使い勝手等についてのご意見を伺うため、電話またはメールにより利用者に連絡することがあります。

## 第6条（本サービスの性質と出力の取扱い）

1. 本サービスの出力は、法規・権利・表現上のリスクの「可能性」を指摘するものであり、適法性、権利侵害がないこと、安全性、媒体の審査を通過することその他いかなる結果も保証するものではありません。
2. 利用者は、出力を参考情報として扱い、実際の公開・納品・出稿の判断を自らの責任で行うものとします。実際の運用においては、必ず専門家（弁護士・弁理士等）のレビューを受けてください。
3. 出力は、AI モデルによる推定を含み、誤りや不完全な内容を含むことがあります。当社は、出力の正確性・完全性・有用性について保証しません。
4. 本サービスは、画像・動画の品質（画質・美しさ・プロンプトへの追従）を判定するものではありません。

## 第7条（入力データの取扱い）

1. 入力データに関する権利は、利用者または正当な権利者に帰属します。
2. 利用者は、入力データを本サービスに送信するために必要な権利または許諾を有していることを保証します。
3. 当社は、入力データを、本サービスの提供（判定、根拠の照合、修正指示の生成）、障害対応、不正利用の防止、および本サービスの改善（判定基準・閾値の調整および評価指標の算出）の目的の範囲で利用します。
4. 判定対象の画像・フレームは、判定のためにのみ利用し、受領から24時間以内に削除します。ただし、判定結果には画像のハッシュ値（sha256）と根拠の版を記録し、保存します。
5. 当社は、入力データを当社の判定モデルの学習には利用しません。
6. 利用者がブランドの資料（ガイドライン、商品マスター等）を取り込んだ場合、当社はこれを当該利用者のブランドの判定にのみ利用し、他の利用者の判定には利用しません。
7. 当社は、顔認識による個人の特定を行いません。

## 第8条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

1. 法令または公序良俗に違反する行為、またはそのおそれのある行為
2. 第三者の知的財産権、肖像権、プライバシーその他の権利を侵害する行為
3. 必要な権利または許諾を有しない入力データを送信する行為
4. 児童の性的搾取に関するもの、その他違法または有害なコンテンツを送信する行為
5. 本サービスのサーバーまたはネットワークに過度な負荷をかける行為、本サービスの運営を妨害する行為
6. 本サービスのリバースエンジニアリング、逆コンパイル、または判定基準・モデルを不正に取得しようとする行為
7. 本サービスの出力を、本サービスと競合するサービスの開発・学習に利用する行為
8. アカウントまたは API キーを第三者に利用させる行為、他人になりすます行為
9. 当社の許諾なく、本サービスを第三者に再販売・再提供する行為
10. その他、当社が不適切と合理的に判断する行為

## 第9条（知的財産権）

1. 本サービス、本サービスに含まれるソフトウェア（MCP の拡張機能、CLI を含みます）、ドキュメントその他一切の知的財産権は、当社または正当な権利者に帰属します。
2. 当社は、利用者に対し、本規約に従って本サービスを利用するために必要な範囲で、MCP の拡張機能および CLI を使用する非独占的・譲渡不能な権利を許諾します。
3. 出力に関する権利は、利用者に帰属するものとします。ただし、当社は、本サービスの提供および改善のため、出力を第7条第3項の目的の範囲で利用できるものとします。

## 第10条（フィードバック）

利用者が当社に提供した本サービスに関する意見・要望等（以下「フィードバック」といいます）について、当社は、利用者に対価を支払うことなく、本サービスの改善その他の目的に自由に利用できるものとします。

## 第11条（本サービスの停止）

当社は、次のいずれかに該当する場合、利用者に事前に通知することなく、本サービスの全部または一部の提供を停止または中断できます。

1. 本サービスに係るシステムの保守、点検または更新を行う場合
2. 火災、停電、天災、通信障害その他の不可抗力により提供が困難となった場合
3. 外部のクラウドサービス、AI モデル提供者、SMS 配信事業者等のサービスが停止した場合
4. その他、当社が停止または中断を必要と判断した場合

## 第12条（利用停止・登録抹消）

当社は、利用者が次のいずれかに該当する場合、事前の通知なく、本サービスの利用停止、API キーの無効化、またはアカウントの抹消を行うことができます。

1. 本規約に違反した場合
2. 登録情報に虚偽があった場合
3. 第17条に定める反社会的勢力に該当し、またはそのおそれがある場合
4. その他、当社が本サービスの利用を適当でないと合理的に判断した場合

## 第13条（退会）

利用者は、当社所定の方法（お問い合わせ窓口への連絡）により、いつでも退会し、アカウントの削除を求めることができます。当社は、退会の連絡を受けてから7日以内にアカウントを削除します。

## 第14条（保証の否認）

当社は、本サービス（ベータ版を含みます）について、事実上または法律上の瑕疵（安全性、信頼性、正確性、完全性、有効性、特定の目的への適合性、セキュリティ上の欠陥、エラーやバグ、権利侵害等を含みます）がないことを明示的にも黙示的にも保証しません。

## 第15条（責任の制限）

1. 当社は、本サービスの利用または利用できなかったことにより利用者に生じた損害について、当社の故意または重過失による場合を除き、責任を負いません。
2. 当社が責任を負う場合であっても、当社の責任は、当該損害が生じた月に利用者が当社に支払った本サービスの利用料金の額（無償期間中は1万円）を上限とし、かつ、通常かつ直接の損害に限られます。
3. 前二項の定めは、消費者契約法その他の法令により無効とされる範囲では適用されません。

## 第16条（秘密保持）

当社は、入力データのうち公開されていない情報を、本規約および個人情報保護方針に定める場合を除き、利用者の同意なく第三者に開示しません。

## 第17条（反社会的勢力の排除）

利用者は、暴力団、暴力団員、暴力団関係企業、総会屋その他これらに準ずる者（以下「反社会的勢力」といいます）に該当しないこと、および反社会的勢力と一切の関係を有しないことを表明し、保証します。

## 第18条（本規約の変更）

1. 当社は、民法第548条の4の規定に基づき、次の場合には、利用者の個別の同意を得ることなく本規約を変更できます。
   - 変更が利用者の一般の利益に適合するとき
   - 変更が本サービスの目的に反せず、かつ、変更の必要性、変更後の内容の相当性その他の変更に係る事情に照らして合理的なものであるとき
2. 当社は、前項による変更にあたり、効力発生日の相当期間前に、変更後の本規約の内容および効力発生日を本サービスのウェブサイトに掲示し、または利用者に通知します。

## 第19条（通知）

当社から利用者への通知は、登録された連絡先メールアドレスへの送信、または本サービスのウェブサイトへの掲示により行います。

## 第20条（権利義務の譲渡禁止）

利用者は、当社の書面による事前の承諾なく、本規約上の地位または権利義務を第三者に譲渡し、または担保に供することはできません。

## 第21条（分離可能性）

本規約のいずれかの条項が無効または執行不能と判断された場合でも、本規約の残りの規定は、引き続き完全に効力を有します。

## 第22条（準拠法・管轄）

1. 本規約は日本法に準拠し、日本法に従って解釈されます。
2. 本サービスに関して当社と利用者との間に生じた紛争については、東京地方裁判所を第一審の専属的合意管轄裁判所とします。

## 第23条（言語）

本規約は日本語を正本とします。英語版その他の翻訳版と内容に相違がある場合は、日本語版が優先します。
